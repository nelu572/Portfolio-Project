# Portfolio-Filling

## 프로젝트 소개

`Portfolio-Filling`은 스팀펑크 감성의 3D FPS 좀비 디펜스 게임을 만들기 위한 프로토타입 개발 프로젝트입니다.

이 프로젝트의 목적은 아이디어를 빠르게 실험하고, 전투 감각과 분위기, 게임 루프를 검증하면서 게임의 핵심 재미를 다듬는 것입니다.  
완성형 출시 버전은 이후 별도의 저장소에서 새롭게 정리해 이어갈 예정입니다.

## 게임 개요

- 장르: 3D FPS
- 서브 장르: 좀비 디펜스
- 테마: 스팀펑크, 공포, 생존
- 비주얼 방향: 미드 폴리, PSX 스타일, 저해상도 기반 거친 공포 연출

## 핵심 플레이

- 1인칭 시점 전투
- 웨이브 기반 좀비 방어
- 목표물 보호
- 무기 운용과 전투 템포 관리
- 자원 회수와 수리 루프
- 점점 강해지는 압박 속에서 버티는 생존 구조

## 분위기와 아트 방향

- 낮은 해상도 느낌의 화면
- 거친 텍스처와 제한된 색감
- 미드 폴리 기반 환경과 오브젝트
- 흔들리는 조명과 불안정한 명암
- 금속, 파이프, 압력계, 증기 같은 스팀펑크 요소

## 현재 상태

현재 저장소는 프로토타입 개발용 정리 단계에 있습니다.

- 기본 씬: `Assets/Scenes/SampleScene.unity`
- 상위 시스템 폴더 구조만 유지 중
- 실제 게임플레이 구현은 다시 단계적으로 쌓아갈 예정

즉, 지금은 “게임의 방향과 실험 기반을 정리한 초기 상태”에 가깝습니다.

## 앞으로 검증할 핵심 요소

이 프로젝트에서 우선적으로 확인할 요소는 다음과 같습니다.

1. FPS 조작과 전투 감각이 재미있는가
2. 좀비 웨이브 압박이 긴장감 있게 작동하는가
3. 방어 목표물과 수리 루프가 플레이 동기를 만드는가
4. 스팀펑크 + PSX 스타일이 실제로 공포 분위기를 살리는가

## 실행

1. Unity Hub에서 프로젝트를 엽니다.
2. Unity 6 `6000.0.68f1` 버전을 사용합니다.
3. `Assets/Scenes/SampleScene.unity`를 엽니다.
4. `Play`로 실행합니다.
