# 게임 기획서

## 1. 게임 개요

- 게임 제목: 미정
- 장르: FPS + 좀비 디펜스
- 플랫폼: PC
- 한 줄 소개:
  - 증기로 움직이는 제국에서 기계 왼팔을 사용하는 주인공이 좀비의 침공을 막아내고 왕을 지키는 스팀펑크 FPS 디펜스 게임.

## 2. 핵심 컨셉

- 코어 루프:
  - 성 안뜰에 몰려오는 좀비를 처치한다.
  - 왕에게 접근하는 적을 차단한다.
  - 웨이브 사이에 탄약, 위치, 왼팔 스킬 구성을 정비한다.
  - 더 강한 웨이브를 버티며 생존 시간을 늘린다.
- 게임 목표:
  - 좀비의 침공을 막으며 생존하고 왕을 보호한다.
- 차별점:
  - 스팀펑크 왕정 세계관.
  - 기계 왼팔 기반 전투 시스템.
  - 미드 폴리 실루엣과 PSX풍 저해상도 분위기.
  - 울트라킬식 빠른 전투 감각과 하프라이프식 산업 호러 분위기 결합.

## 3. 세계관 & 스토리

- 배경 설정:
  - 증기 기술이 발전한 대체 역사 세계.
  - 왕정 체제가 유지되고 있으며, 기계화와 노동 문제를 둘러싼 러다이트 운동이 격화된다.
  - 시위와 진압이 이어지던 중 정체불명의 감염 사태가 발생하고, 성 주변 시민들이 좀비화된다.
- 시놉시스:
  - 왕실 기술부대 소속 주인공은 사고로 잃은 왼팔을 증기 기계팔로 대체한 병사다.
  - 감염된 시민과 기계 장치에 오염된 좀비들이 성으로 밀려오고, 주인공은 직접 무기를 든 왕과 함께 마지막 방어선을 지킨다.
  - 플레이어는 웨이브를 버티며 감염 확산의 원인과 비행선 세력의 개입을 추적한다.
- 주요 등장인물:
  - 주인공:
    - 남성.
    - 기계 왼팔을 사용한다.
    - 왕을 지키는 왕실 기술부대원.
  - 왕:
    - 보호 대상이지만 완전히 무력하지 않다.
    - 무기를 들고 직접 싸우는 전투형 동료.
    - 프로토타입에서는 중앙 방어 목표물로 표현한다.
  - 좀비:
    - 시민 좀비: 기본 잡몹. 다수로 몰려와 왕을 공격한다.
    - 기계 좀비: 중간보스 후보. 증기 장치나 금속 부품이 감염된 형태.
  - 적 오브젝트:
    - 비행선: 후반 웨이브나 보스 연출 후보.

## 4. 게임플레이

- 기본 조작:
  - 이동: WASD
  - 점프: Space
  - 달리기: Shift
  - 웅크리기: Ctrl
  - 사격/왼팔 스킬: 좌클릭
  - 재장전: R
  - 상호작용: F
  - 무기 전환:
    - 기계 왼팔 능력: 그래플링 훅, 전기톱, 전격 방출.
    - 권총/리볼버: 기본 잡몹 처리와 정밀 사격용.
    - 기관단총/산탄총/저격총: 중거리 압박, 근거리 제압, 고가치 표적 제거용.
    - 폭발물: 다이너마이트, 열압력탄.
- 핵심 메커니즘:
  - FPS 전투.
  - 웨이브 디펜스.
  - 기계 왼팔 스킬 교체.
  - 왕 보호.
- 게임 흐름:
  - 시작: 성 안뜰 중앙에서 왕과 함께 방어를 시작한다.
  - 중반: 웨이브 규모가 커지고, 시민 좀비 외의 특수 좀비가 추가된다.
  - 클리어: 지정 웨이브를 모두 막거나 보스급 위협을 제거한다.
- 난이도 설계:
  - 웨이브가 진행될수록 적 수와 압박 방향이 증가한다.
  - 이후 기계 좀비, 비행선, 특수 감염체를 통해 위협 종류를 늘린다.

## 5. 콘텐츠

- 스테이지 / 맵 구성:
  - 성 안뜰:
    - 중앙에 왕이 위치한다.
    - 사방의 게이트와 성벽 틈으로 좀비가 침입한다.
    - 보일러, 황동 파이프, 압력 탱크가 엄폐물과 분위기 오브젝트 역할을 한다.
- 캐릭터 / 유닛:
  - 플레이어.
  - 왕.
  - 시민 좀비.
  - 기계 좀비.
- 아이템 / 장비:
  - 기계 왼팔:
    - 그래플링 훅.
    - 전기톱.
    - 전격 방출.
  - 권총 / 리볼버:
    - 기본 잡몹 처리용.
    - 시민 좀비보다 단단하지만 고급 탄을 쓰기 아까운 적 처리용.
  - 기관단총 / 산탄총 / 저격총:
    - 빠른 연사 화기.
    - 공기압축식 산탄총.
    - 전격 저격총.
  - 폭발물:
    - 다이너마이트.
    - 열압력탄.
- 보스:
  - 기계 좀비 지휘체.
  - 비행선 기반 원거리 압박 보스.

## 6. UI / UX

- HUD 요소:
  - 플레이어 체력.
  - 왕 체력.
  - 탄약.
  - 웨이브 표시.
  - 남은 적 수.
  - 왼팔 스킬 UI.
- 주요 화면 목록:
  - 메인 메뉴.
  - 인게임 HUD.
  - 게임 오버 화면.

## 7. 아트 방향성

- 비주얼 스타일:
  - 미드 폴리.
  - PSX 스타일.
  - 거친 실루엣과 낮은 해상도에서도 읽히는 형태.
- 컬러 팔레트 방향:
  - 황동, 검은 금속, 탁한 녹색, 어두운 회색, 붉은 경고등.
  - 현대적인 청결함보다 오래된 산업 장치와 왕실 장식이 섞인 느낌.
- 레퍼런스:
  - 스팀펑크 산업 장치.
  - 하프라이프 1/2의 산업 시설 분위기.
  - 울트라킬의 빠른 전투 리듬.

## 8. 사운드 방향성

- BGM 분위기:
  - 낮고 반복적인 증기 기관 리듬.
  - 웨이브가 올라갈수록 금속 타격음과 불안한 현악 계열을 강화한다.
- 효과음 포인트:
  - 증기 배출음.
  - 기계 왼팔 구동음.
  - 리볼버 장전음.
  - 좀비의 젖은 숨소리와 금속 긁힘.
  - 왕 피격 시 명확한 경고음.

## 9. 레퍼런스 게임

- 울트라킬:
  - 빠른 전투 액션.
  - 공격적인 무기 사용감.
- 하프라이프 1/2:
  - 그래픽과 산업 호러 분위기.
  - 기능적인 공간 구성.

## 10. 현재 프로토타입 반영 기준

- `GameScene`은 성 안뜰 방어 프로토타입으로 사용한다.
- 중앙 목표물은 발전기가 아니라 왕으로 표현한다.
- 기본 적은 시민 좀비로 표현한다.
- 플레이어의 현재 사격은 스팀 리볼버/기계 왼팔 전격 사격의 임시 버전으로 취급한다.
- 추후 왼팔 스킬, 무기 전환, 기계 좀비, 비행선은 단계적으로 확장한다.
