# 파일 변경 이력

## 현재 커밋 안 된 작업

- 플레이 감각 중심 2차 프로토타입 수정을 진행했다.
  - 사격 시 카메라 킥, 화면 흔들림, 무기 반동, 총구 화염, 탄착 스파크를 추가했다.
  - 명중/처치/탄약 없음/재장전 상태가 HUD에 명확히 보이도록 수정했다.
  - 좀비가 플레이어 근접 시 플레이어를 우선 추적하고, 방치되면 왕을 공격하도록 AI를 바꿨다.
  - 좀비 피격 경직, 넉백, 색상 플래시를 추가했다.
  - 왕이 주변 좀비를 자동 사격하는 동료 전투 스크립트를 추가했다.
  - 웨이브가 즉시 몰려나오지 않고 게이트에서 간격을 두고 스폰되도록 변경했다.
  - 중앙 방어 구역, 3개 침입 게이트, 엄폐물, 고지대, 보일러/압력탱크 배치를 다시 정리했다.
  - `Assets/Scripts/Defense/KingAllyCombat.cs`
- 사용자 기획서를 정리한 게임 기획서 문서를 추가하고, 프로토타입을 왕 보호 스팀펑크 FPS 디펜스 방향으로 조정했다.
  - `Harness/Docs/Planning/GAME_DESIGN_DOCUMENT.md`
  - HUD의 방어 목표 표기를 발전기에서 왕으로 변경했다.
  - 플레이어 무기 표기를 증기 리볼버와 기계 왼팔 전격으로 변경했다.
  - 중앙 방어 목표물을 왕 형태로 생성하고 왕관/무기 비주얼을 추가했다.
  - 성 안뜰, 침입 게이트, 왕실 배너, 압력 탱크 등 스팀펑크 성 방어 소품을 추가했다.
- `GameScene`에서 바로 실행되는 FPS 웨이브 디펜스 프로토타입 런타임을 추가했다.
  - 좌클릭 히트스캔 사격, 탄창/재장전, 조준점 피드백을 추가했다.
  - 플레이어 체력, 방어 발전기 체력, 임시 좀비 추적/공격/사망 루프를 추가했다.
  - 웨이브 디렉터, 스폰 지점 자동 구성, 프로토타입 HUD, 임시 스팀펑크 소품 생성을 추가했다.
  - `Assets/Scripts/Core/IDamageable.cs`
  - `Assets/Scripts/Core/PrototypeBootstrapper.cs`
  - `Assets/Scripts/Core/PrototypeHud.cs`
  - `Assets/Scripts/Core/WaveDirector.cs`
  - `Assets/Scripts/Defense/DefenseObjective.cs`
  - `Assets/Scripts/Enemy/ZombieEnemy.cs`
  - `Assets/Scripts/Player/PlayerHealth.cs`
  - `Assets/Scripts/Weapon/PlayerHitscanWeapon.cs`
- 현재 하네스 구조를 바탕으로 다른 프로젝트에서 하네스를 생성할 수 있는 제작 프롬프트를 추가했다.
  - `Harness/HARNESS_CREATION_PROMPT.md`

## 2026-06-08

- 플레이 감각 중심 2차 프로토타입 수정을 진행했다.
  - 무기 발사 피드백, 명중 피드백, 재장전/탄약 UI를 강화했다.
  - 좀비 AI를 플레이어 우선 위협과 왕 공격 전환 구조로 바꾸고, 피격 경직/넉백을 추가했다.
  - 왕이 주변 좀비를 자동 사격하는 동료 행동을 추가했다.
  - 웨이브 스폰을 간격 기반으로 바꾸고 중앙 메시지를 추가했다.
  - 맵 자동 구성을 3개 침입 게이트, 왕 방어 구역, 엄폐물, 고지대 중심으로 재배치했다.
- 사용자 기획서를 바탕으로 게임 기획서 문서를 추가했다.
  - `Harness/Docs/Planning/GAME_DESIGN_DOCUMENT.md`
  - 세계관, 코어 루프, 조작, 장비 후보, UI, 아트/사운드 방향성을 프로토타입 기준으로 정리했다.
- 기존 프로토타입 런타임을 왕 보호 스팀펑크 FPS 디펜스 방향으로 수정했다.
  - 중앙 방어 목표물을 왕으로 표현하고 HUD도 왕 체력 중심으로 바꿨다.
  - 플레이어 무기를 증기 리볼버/기계 왼팔 전격 임시 표현으로 바꿨다.
  - 성 안뜰, 침입 게이트, 왕실 배너, 압력 탱크를 추가해 맵 분위기를 기획서에 맞췄다.
- FPS 웨이브 디펜스 프로토타입 1차 런타임을 추가했다.
  - `GameScene` 로드 시 기존 `PlayerRoot`와 `Main Camera`를 찾아 플레이 가능한 전투 루프를 자동 구성한다.
  - 플레이어 사격, 탄약/재장전, 피격 가능한 좀비, 방어 목표물, 웨이브 진행, HUD를 추가했다.
  - 황동 파이프, 보일러 블록, 경고등 성격의 임시 소품을 생성해 PSX/스팀펑크 방향성을 빠르게 확인할 수 있게 했다.
