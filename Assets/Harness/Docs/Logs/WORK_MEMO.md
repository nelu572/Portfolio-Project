# 작업 메모

이 문서는 작업 중 남겨둘 메모, 판단 보류 사항, 다음 확인 포인트를 기록하는 용도다.

규칙:
- `WORK_ORDER.md`에는 메모를 적지 않는다.
- 작업 지시와 별개인 메모는 이 문서에 기록한다.
- 변경 이력은 `FILE_CHANGE_LOG.md`에 기록하고, 생각 정리나 보류 항목은 여기 적는다.
