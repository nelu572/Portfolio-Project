# 비주얼 하네스

## 목표 분위기

- 거친 모서리를 가진 미드폴리 실루엣
- PSX 느낌의 저해상도 표현
- 약간 거칠고 불안정하게 느껴지는 공포 분위기
- 스팀펑크 기계 장치, 파이프, 압력 탱크, 밸브, 금속 이음새

## 권장 방향

1. 잔디테일보다는 굵고 읽기 쉬운 형태를 우선한다.
2. 텍스처는 낮은 해상도에서도 형태와 재질감이 어느 정도 읽히면 충분하다.
3. 너무 깨끗하고 현대적인 표면은 줄이되, 프로토타입 단계에서는 과하게 엄격하게 묶지 않는다.
4. 조명은 필요하면 깜빡임이나 강한 명암 대비를 활용할 수 있다.
5. 배경 오브젝트는 길찾기, 방어, 분위기 형성에 도움이 되면 적극적으로 사용한다.
6. 색감은 황동, 검정, 붉은색, 탁한 초록, 회색 계열을 기본 참고로 삼되, 테스트 단계에서는 변형 가능하다.
7. 모델은 거친 렌더링에서도 중거리 이상에서 형태가 읽히는 것을 우선한다.

## 현재 적용 상태

- 현재는 비주얼 전용 런타임 하네스 구현보다, 방향성을 문서로 먼저 정리한 상태다.
- 실제 비주얼 테스트용 씬이나 보조 스크립트는 이후 필요할 때 다시 붙인다.

## 아트 검수 체크리스트

- 낮은 해상도에서도 실루엣이 읽히는가?
- 너무 깨끗하거나 현대적으로 보이지 않는가?
- 스팀펑크 호러 감각을 강화하는가?
- 어두운 조명이나 거친 렌더링에서도 분위기가 유지되는가?
