# 출시 로드맵

## 현재 진행 상황

- 현재 진행 단계: 구현 리셋 후 하네스 문서와 폴더 구조만 유지하는 상태 정리 완료
- 현재 집중 단계: 1단계 플레이 가능한 FPS 기반을 새 구조에서 다시 시작할 준비
- 다음 우선 단계: 1단계 플레이어 이동/시점, 2단계 첫 무기 패스, 3단계 첫 좀비 원형

1. 플레이 가능한 FPS 기반
   - 이동, 시점, 점프 감각 보정
   - 발소리와 피격 피드백 추가
2. 첫 무기 패스
   - 반동, 장전 피드백, 총구 화염, 오디오 추가
3. 첫 좀비 원형 완성
   - 실루엣 개선, 애니메이션, 피격 반응 추가
4. 스폰 루프 구축
   - 스폰 템포, 안전 체크, 전투 가독성 조정
5. 웨이브 시스템 확장
   - 난이도 증가 규칙, 웨이브 사이 휴식, 보상 구조 추가
6. 방어 목표물 강화
   - 목표물 UI, 실패 상태, 수리 루프 추가
7. 자원과 바리케이드 루프
   - 스크랩 드랍, 수리 비용, 설치 가능 여부 검증
8. 스팀펑크 맵 블록아웃
   - 경기장 형태, 초크포인트, 이동 경로, 사선 설계
9. PSX 비주얼 패스
   - 픽셀화, 텍스처 규칙, 팔레트 관리, 불안정한 조명
10. 공포 연출 강화
   - 오디오 스팅, 안개, 실루엣 활용, 긴장 UI 피드백
11. UI 패스
   - HUD, 일시정지/설정, 웨이브 상태, 목표물 상태
12. 세이브와 설정
   - 영구 설정 저장, 진행도, 키 옵션
13. 최적화와 빌드 안정화
   - 성능 예산, 메모리 점검, 에셋 정리
14. 출시 준비
   - 스팀 페이지 자산, 컨트롤러 대응, QA 체크리스트, 스토어 빌드
