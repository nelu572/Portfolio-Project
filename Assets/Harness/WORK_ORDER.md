# 작업 지시서

이 파일은 앞으로 AI에게 작업을 지시할 때 사용하는 공용 명령 파일이다.

사용 방법:
1. 아래 항목을 채운다.
2. AI에게 " `Assets/Harness/WORK_ORDER.md` 기준으로 작업해" 라고 지시한다.
3. 작업이 끝나면 다음 요청으로 내용을 덮어쓰거나 새 항목으로 갱신한다.
4. AI에게 "메모 작업해" 라고 지시하면, AI는 이 파일을 먼저 읽고 여기에 적힌 작업 내용을 실제로 수행한다.

주의:
- `WORK_ORDER.md`는 작업 지시 템플릿 파일이다.
- 사용자가 "지워", "비워", "초기화"처럼 명시적으로 요청한 경우에만 아래 작업 내용 영역을 비울 수 있다.
- 그 경우에도 상단 안내와 템플릿 구조는 남긴다.
- 메모성 내용은 이 파일에 적지 않고 `Assets/Harness/Docs/Logs/FILE_CHANGE_LOG.md`의 메모 파트에 기록한다.

---

## 작업 이름

- 하네스 수정

## 상세 요구사항

- 파일 로그에 커밋 안된 부분, 작업 지시서는 커밋 푸시하지 않는다.(항상 비워져있는 상태를 유지해야함)
- "메모 작업 n번째 해"와 같이 명령하면 상세 요구사항에 번호만 작업한다.
- 작업 지시서 맨 밑에 "유저 메모장" 파트를 작성한다.
    - 이 파트는 작업을 하지 않는다.
    - 비우지도 지우지도 않는다.
    - 커밋도 당연히 하지 않는다.
- 로그를 비운다, 또한 작업을 나열할때 최근에 한 작업을 위에 적는다.
