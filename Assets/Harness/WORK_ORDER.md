# 작업 지시서

이 파일은 앞으로 AI에게 작업을 지시할 때 사용하는 공용 명령 파일이다.

사용 방법:
1. 아래 항목을 채운다.
2. AI에게 " `Assets/Harness/WORK_ORDER.md` 기준으로 작업해" 라고 지시한다.
3. 작업이 끝나면 다음 요청으로 내용을 덮어쓰거나 새 항목으로 갱신한다.
4. AI에게 "메모 작업해" 라고 지시하면, AI는 이 파일을 먼저 읽고 여기에 적힌 작업 내용을 실제로 수행한다.

주의:
- `WORK_ORDER.md`는 작업 지시 템플릿 파일이다.
- 사용자가 "지워", "비워", "초기화"처럼 명시적으로 요청한 경우에만 아래 작업 내용 영역을 비울 수 있다.
- 그 경우에도 상단 안내와 템플릿 구조는 남긴다.
- 메모성 내용은 이 파일에 적지 않고 `Assets/Harness/Docs/Logs/WORK_MEMO.md` 또는 `Assets/Harness/Docs/Logs/FILE_CHANGE_LOG.md`에 기록한다.

## 상세 요구사항

- "즉시 틀린 정보" 파트
    - 내용을 확인하고 그 내용에 맞게 수정한다.
- "방향성 충돌" 파트
    - "프로토타입 제작"이라는 방향성으로 전면 수정한다.
    - 깃허브 내용은 현재는 메인 브랜치 직커밋이지만 기능 개발시에 디벨롭 브랜치 제작 후 git flow 방식을 사용할 것 이다.
- "VISUAL_HARNESS가 빡빡한 이유" 파트
    - 널널하게 수정한다
- "애매모호한 표현" 파트
    - 급한것이 아니면 무시한다
    - 프로토타입 개발의 의미는 FPS 시스템 등 인게임의 내용들을 의미한다.
